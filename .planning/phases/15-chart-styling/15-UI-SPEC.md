## Chart Styling Contract

This section is specific to Phase 15 and extends the generic template.

### Gradient Fills

**Area Charts** (TrendChart, AccessoryDetail activity AreaChart):

```
<linearGradient id="{uniqueId}" x1="0" y1="0" x2="0" y2="1">
  <stop offset="5%"  stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0.15} />
  <stop offset="95%" stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0} />
</linearGradient>
```

- Unique gradient ID per component instance using accent values as key (see TrendChart gradientId pattern)
- `fill="url(#gradientId)"` on `<Area>` element
- Stroke: `stroke="rgb(var(--hc-accent-rgb))"` at `strokeWidth={2}`

**Bar Charts** (ActivityChart): Replace per-Cell opacity pattern with a single top-to-bottom gradient fill.

```
<linearGradient id="activityBarGradient" x1="0" y1="0" x2="0" y2="1">
  <stop offset="5%"  stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0.85} />
  <stop offset="95%" stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0.35} />
</linearGradient>
```

- Remove all `<Cell>` children from `<Bar>`
- Set `fill="url(#activityBarGradient)"` directly on `<Bar>`
- Retain `radius={[3, 3, 0, 0]}` and `maxBarSize={20}`

**Sparkline** (KpiCards — Events Today card only):

```
<linearGradient id="sparklineGradient" x1="0" y1="0" x2="0" y2="1">
  <stop offset="5%"  stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0.3} />
  <stop offset="95%" stopColor="rgb(var(--hc-accent-rgb))" stopOpacity={0} />
</linearGradient>
```

- Denser fill (0.3 vs 0.15) for legibility at compact height
- Stroke: `stroke="rgb(var(--hc-accent-rgb))"` at `strokeWidth={1.5}`

**Heatmap components** (WeekdayHeatmap, HeatmapLane, HeatmapGrid): Already use `rgba(var(--hc-accent-rgb), …)` opacity scale — no gradient treatment. Preserve existing cell-based approach per D-08.

**PieChart / Donut** (AccessoryDetail state duration): Flat fill only — no gradient treatment. Gradient on a radial pie sector reduces readability for small slices. Retain `DONUT_COLORS` array for categorical distinction per D-09 ruling.

### Curve Type

All `<Line>` and `<Area>` elements: `type="monotone"` (already applied in TrendChart; extend to AccessoryDetail AreaChart and LineChart).

### Line Chart Stroke Contract

Standalone `<Line>` elements in AccessoryDetail (numeric characteristic trend charts):

- `stroke="rgb(var(--hc-accent-rgb))"`
- `strokeWidth={2}`
- `dot={false}`
- `activeDot={{ r: 4, strokeWidth: 0 }}`
- No fill (lines do not get gradient treatment — gradient is for Area charts only)

### Animation

- Use Recharts v3 default animation (enabled, 400ms duration)
- Do NOT apply CSS `transition` on chart container width or `grid-template-columns` — avoids ResizeObserver re-render churn on low-power hardware (RPi/NAS) per Roadmap v1.2 decision
- Sparkline: `isAnimationActive={false}` — sparkline is decorative and sits inside a card that already fades in; double animation is distracting

### Sparkline Dimensions

- Height: 36px (`height={36}`)
- Width: 100% of remaining card space after icon column (`width="100%"` via `ResponsiveContainer`)
- No axes, no tooltip, no grid, no legend, no dots
- No margin (`margin={{ top: 0, right: 0, left: 0, bottom: 0 }}`)
- Positioned below the count value inside the KPI card body
- Data source: `useDailyStats(7)` — reuse existing hook, slice to last 7 data points, no new API endpoint needed (per D-07)

### Recharts v3 Upgrade

- Bump `recharts` from `^2.12.7` to `^3.x` (latest stable) in `web/package.json`
- Add `react-is` override in `web/package.json` `overrides` field if peer dep check against React 19 fails
- No Recharts v2-specific API patterns should remain after this phase
- Preserve `ResponsiveContainer`, `CartesianGrid`, `XAxis`, `YAxis`, `Tooltip`, `Area`, `AreaChart`, `Bar`, `BarChart`, `Line`, `LineChart`, `PieChart`, `Cell` — all still present in v3
