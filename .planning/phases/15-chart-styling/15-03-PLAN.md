4. **Add sparkline data hook and memo** inside the `KpiCards` function, after the existing `useDailyStats(dashboardDays)` call (after line 42):
   ```jsx
   const { data: sparkDaily } = useDailyStats(7);
   const accent = useAccentRgb();
   const accentStr = `rgb(${accent[0]},${accent[1]},${accent[2]})`;

   const sparkData = useMemo(() => {
     const dayMap = new Map((sparkDaily ?? []).map((d) => [String(d.day).slice(0, 10), Number(d.count ?? 0)]));
     return Array.from({ length: 7 }, (_, i) => {
       const key = format(subDays(new Date(), 6 - i), 'yyyy-MM-dd');
       return { i, count: dayMap.get(key) ?? 0 };
     });
   }, [sparkDaily]);
   ```
   Note: `format` and `subDays` are already imported from `date-fns` at line 1. TanStack Query will deduplicate the `useDailyStats(7)` call if `dashboardDays` is already 7.

5. **Add sparkline render inside the TODAY card**. In the Card rendering loop (lines 99-121), after the closing `</div>` of the inner flex container (line 117) and before `</Card.Body>` (line 118), add a conditional sparkline block:
   ```jsx
   {def.key === 'today' && sparkData.length > 0 && (
     <div className="mt-2 -mx-1">
       <ResponsiveContainer width="100%" height={36}>
         <AreaChart data={sparkData} margin={{ top: 0, right: 0, left: 0, bottom: 0 }}>
           <defs>
             <linearGradient id="sparklineGradient" x1="0" y1="0" x2="0" y2="1">
               <stop offset="5%"  stopColor={accentStr} stopOpacity={0.3} />
               <stop offset="95%" stopColor={accentStr} stopOpacity={0}   />
             </linearGradient>
           </defs>
           <Area
             type="monotone"
             dataKey="count"
             stroke={accentStr}
             strokeWidth={1.5}
             fill="url(#sparklineGradient)"
             dot={false}
             isAnimationActive={false}
           />
         </AreaChart>
       </ResponsiveContainer>
     </div>
   )}
   ```

The sparkline renders: 36px tall, full card width, gradient fill with 0.3→0 opacity (denser than TrendChart's 0.15 for legibility at small size), monotone curve, no axes/tooltip/grid/legend/dots, no animation. Static gradient ID `"sparklineGradient"` is safe because only one sparkline renders per page.
