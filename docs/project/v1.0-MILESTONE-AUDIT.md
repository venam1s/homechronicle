1. **Dead code: `normalizeRateLimitValue`** — Exported from utils.js (Phase 6) but no router imports it. All routers use `parseIntInRange` for rate-limit env var parsing. Should be removed or wired in.

Mocks silently ignored; tests pass using real functions.

3. **Stale documentation: init.sql** — `db/init.sql` removed from all production Docker configs (MIG-04 satisfied), but CLAUDE.md and docs still reference it as the schema source. Documentation needs update.

4. **UX gap: estimated flag** — `/api/events` response includes `estimated: true/false` (PERF-03 satisfied), but no web UI component displays an approximation indicator. UX concern for future milestone.

5. **RTR-10 line deviation** — `index.js` is 477 lines vs ~300-400 target. Content criterion fully satisfied; all helper definitions extracted. 77-line overage documented as known deviation from plan estimate.
